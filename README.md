-🛍️ Storks (Marketplace de Segunda Mano)

Plataforma web de compra y venta de artículos de segunda mano entre particulares. 
Permite a los usuarios dar una segunda vida a sus productos de forma sencilla, segura y directa.

-✨ Características principales

Gestión de usuarios: Registro, inicio de sesión y perfiles personalizados con historial de ventas y valoraciones.

Catálogo de productos: Publicación de artículos con subida de múltiples imágenes, descripción, estado del producto y precio.

Búsqueda y filtrado: Búsqueda dinámica por palabras clave y filtros por categoría, talla, estado o rango de precios.

Sistema de favoritos: Posibilidad de guardar artículos en una lista de deseos para revisarlos más tarde.

Proceso de compra: Carrito o compra directa con simulación de pasarela de pago y gestión de estado del pedido.
